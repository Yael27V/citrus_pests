# Guía de Contribución

¡Gracias por tu interés en contribuir a Plagas Beta!

## Cómo contribuir

1. **Forkea** este repositorio y crea una rama para tu feature o fix.
2. **Haz tus cambios** siguiendo las buenas prácticas de código y estilo.
3. **Agrega comentarios** y documentación si es necesario.
4. **Asegúrate de que el proyecto compile y pase el linter** (`npm run lint`).
5. **Haz un Pull Request** describiendo claramente tu aporte.

## Reglas básicas
- Usa nombres descriptivos para commits y ramas.
- No subas archivos de configuración personal ni credenciales.
- Si agregas dependencias, justifica su uso.
- Mantén la documentación actualizada.

## Contacto
Para dudas o sugerencias, abre un issue o contacta a los mantenedores.
